## Instruções permanentes do projeto

- **Push automático:** sempre que concluir uma tarefa (após validar com typecheck/lint/build), faça `git commit` e `git push` imediatamente, sem pedir confirmação. Esta regra vale para esta e todas as demais sessões.
- **Idioma do conteúdo:** todo texto de interface/landing em português deve ser mantido em português (não traduzir para inglês nem usar lorem ipsum).
